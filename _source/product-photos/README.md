## ⚠️ Чего не хватает для экспортного сайта

Имеющегося достаточно, чтобы показать продукт, но не достаточно, чтобы убедить импортёра.
Нужна отдельная фотосессия:

1. **Производственная линия в работе** — розлив, укупорка, этикетировка. Есть один кадр ящиков.
2. **Склад и паллеты** — закупщик хочет видеть, как товар едет. Нет ни одного кадра.
3. **Отгрузка / контейнер** — доказательство, что экспорт реален.
4. **Лаборатория и контроль качества** — под раздел сертификатов.
5. **Источник воды** — есть только постановочный кадр на камнях, самого источника нет.
6. **Групповые кадры линейки** — вся вода вместе, вся кола вместе, на прозрачном фоне.
7. **Стеклянная бутылка 0,5 л, 6 л PET, линейка Sport** — эти SKU есть в экспортном каталоге,
   но фото нет ни одного.
8. **Garni Cola 1,5 л** — есть только 0,5 л; чертёж 1,5 л есть, рендера нет.
9. **Команда и завод снаружи** — для страницы «О компании».

## Технические замечания

- Бутылки Garni Cola — **PNG с альфа-каналом**, обтравка не нужна.
- Акварельные фрукты — тоже с альфой, готовы как декоративный слой.
- Вода — JPG на белом фоне, для тёмных секций потребуется обтравка.
- Файлы тяжёлые (до 8 МБ). Перед публикацией — WebP/AVIF + `srcset`.
- Часть изображений в брендбуках повторяется на разных страницах; дубликаты отфильтрованы,
  соответствия страницам сохранены в [_manifest.json](_manifest.json).
