# 1. Garni Crystalline — Brand Identity Guide

## Логотип
Колоннада храма Гарни над словом **GARNI**, ниже разрядкой **CRYSTALLINE**.

**Варианты:**
1. Полный логотип (иконка + текст)
2. Только текстовый знак — `GARNI CRYSTALLINE`
3. Только иконка — колоннада
4. **Армянская версия** — `ԳԱՌՆԻ ԿՐԻՍՏԱԼԼԱՅՆ`, все правила применяются к ней так же

Текстовый знак и иконка предназначены для случаев, когда полный логотип нечитаем на малых размерах.

**Охранное поле:** равно высоте буквы «G» логотипа, со всех сторон.
**Минимальный размер:** 80 px в цифре · 20 мм в печати.

**Цветовые версии:** позитив (синий на белом) · негатив (белый на синем) · чёрная · белая.
Монохромные версии — только для специфических печатных требований.

## Что запрещено (8 правил)
Не менять цвета логотипа · не двигать иконку · не ставить на изображение с плохим контрастом ·
не менять размер отдельных элементов · не поворачивать · не размещать объекты в охранном поле ·
не сжимать/растягивать непропорционально · не добавлять тень, скос, свечение и прочие эффекты.

## Логотип на фото
Разрешено размещение на изображениях при достаточном контрасте. В большинстве случаев логотип
на фото ставится **белым**, кроме случаев, когда фон настолько светлый, что допустим цветной.
Показаны варианты с цветной плашкой-подложкой (синей и красной) под подпись.

## Что из этого обязательно перенести на новый сайт

1. **Цвета Garni Crystalline** — `#006FBA` как основной, а не текущие `#00A8E1` / `#2693AA`.
2. **Цвета Garni Cola** — `#DA2128` + чёрный, шесть вкусовых цветов для карточек вкусов.
3. **Фавикон** — скорописная «G», 32×32. Он спроектирован ровно под rocarm.am и до сих пор не поставлен.
4. **Слоган Garni Cola** на трёх языках — готовый, утверждённый текст.
5. **Шрифты.** Neue Frutiger World и Mont — коммерческие, нужны веб-лицензии.
   Если бюджета на лицензии нет, подобрать метрически близкие замены и зафиксировать это решение
   (Neue Frutiger World → Frutiger-подобные гротески; Mont → Gilroy / Poppins / Montserrat).
   Armaria Bold и Comic Sans — только для этикеток, на сайт не переносить.
6. **Акварельные фрукты** Garni Cola — готовый визуальный язык для раздела вкусов.
7. **Логотипы в трёх языковых версиях** (лат. и арм.) для обоих брендов.
8. **Правила охранного поля и минимальных размеров** — заложить в CSS как отступы вокруг логотипа.
